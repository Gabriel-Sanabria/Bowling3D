## 📖 Sobre el Proyecto

**Bowling 3D** es un juego de bolos donde el jugador controla una bola para derribar los pinos en una pista. 
Ajusta la dirección, calcula la fuerza y encuentra el ángulo perfecto para lograr strikes y spares. 

¿Podrás dominar la pista y convertirte en un maestro del bowling?

---

## ✨ Características Principales

🎳 **Mecánicas de Juego**
- Sistema de puntuación con strikes y spares
- Múltiples intentos por ronda para derribar todos los pinos

🎯 **Sistema de Lanzamiento**
- Control preciso de dirección y fuerza de la bola
- Física realista de colisiones entre bola y pinos

📷 **Cámara Dinámica**
- Seguimiento automático de la bola durante el lanzamiento
- Diferentes ángulos para mejor visualización de la jugada

🎨 **Personalización**
- Diferentes skins y colores para la bola
- Variedad de diseños y estilos para los pinos

## 🚀 Cómo Ejecutar

1. Clona este repositorio
2. Abre el proyecto en **Unity 2019.4.17f1** (o superior compatible)
3. Abre la escena **"Bowling-Menu"** desde [Assets/Escenas](Assets/Escenas)
4. Presiona el botón Play en el editor de Unity
5. ¡Juega y derriba todos los pinos!
